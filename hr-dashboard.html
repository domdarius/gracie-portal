Konfigurasi Bot

Panduan Setup (3 langkah)

1

Buat Bot via @BotFather

Buka Telegram, cari @BotFather, kirim /newbot, beri nama bot, lalu copy Bot Token yang diberikan.

/newbot → masukkan nama → copy token
2

Dapatkan Chat ID

Buat grup Telegram untuk HR, tambahkan bot ke grup, lalu kirim pesan di grup. Buka URL berikut untuk lihat Chat ID:

https://api.telegram.org/bot[TOKEN]/getUpdates
3

Isi token & Chat ID di atas, klik Test

Sistem akan kirim pesan test ke grup HR. Setelah berhasil, semua notifikasi pengajuan cuti & reimbursement akan otomatis terkirim.
